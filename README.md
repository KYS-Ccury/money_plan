# 자본금 계산기 (Python + QML)

보증금 · 월세 · 관리비 · 대출 이자 · 은행 예금 등 항목을 리스트로 **추가/제거**하고,
기간(개월)과 **목표 자본금**을 기준으로 순 자본과 달성률을 계산하는 데스크톱 앱입니다.

백엔드(Python)와 프론트엔드(QML)를 분리한 구조입니다.

- `capital_calc/model.py` — 순수 계산 로직. Qt 를 전혀 모름.
- `capital_calc/backend.py` — 모델을 `QObject` / `QAbstractListModel` 로 감싸 QML 에 프로퍼티·시그널·슬롯으로 노출.
- `qml/` — 화면·레이아웃·애니메이션. Python 을 모르고 `backend` 객체만 바인딩.

QML 은 Qt Quick 씬그래프가 GPU(OpenGL/Direct3D)로 렌더링합니다.
항목 추가/삭제 슬라이드, 숫자 롤링, 진행 바 보간과 하이라이트, 그래프가 그려지는 애니메이션, 팝업 등장 효과가 들어 있습니다.
예전 OpenGL(GLFW + Dear ImGui) 버전은 `main_imgui.py` 로 남겨 두었습니다.

## 실행

```bash
pip install -r requirements.txt
python main.py
```

## 구조

| 파일 | 역할 |
|---|---|
| `main.py` | 실행 진입점 (PySide6 + QML). `--screenshot` 는 테스트용 |
| `main_imgui.py` | 예전 OpenGL(ImGui) 버전 진입점 |

| `capital_calc/backend.py` | QML 브리지: `Backend`(QObject), `ItemListModel` |

## 항목 분류와 계산 방식

| 분류 | 금액의 의미 | 보유 자금 | 일시 지출 | 월 지출 | 월 수입 | 일시 수입 |
|---|---|---|---|---|---|---|
| 보증금 | 보증금 (지출일) | | ✔ | | | |
| 월세 | 월세 (적용 기간) | | | ✔ | | |
| 관리비 | 월 관리비 (적용 기간) | | | ✔ | | |
| 고정 지출(월) | 매달 나가는 돈 (적용 기간) | | | ✔ | | |
| 대출/이자 | 대출 원금 + 연이율 (적용 기간, 중도 상환) | ✔ (옵션) | | 잔액×이율÷12 | | |
| 은행 예금 | 예금액 + 연이율 | ✔ | | | 원금×이율÷12 | |
| 현금/자산 | 보유 금액 | ✔ | | | | |
| 일시 지출 | 지출액 (지출일) | | ✔ | | | |
| 기타 수입(월) | 월 수입 (적용 기간) | | | | ✔ | |
| 일시 수입 | 수입액 (수입일) | | | | | ✔ |

지출과 수입 모두 **매달 오고 가는 것**과 **한 번만 오고 가는 것**으로 나뉩니다.

- 매달 나감: `월세`, `관리비`, `고정 지출(월)`, 대출 이자. 보험료·통신비·식비·교통비처럼 이름이 따로 없는 월 지출은 `고정 지출(월)` 에 넣습니다.
- 한 번 나감: `보증금`, `일시 지출`. 이사비·중개수수료·취득세 같은 것입니다.
- 매달 들어옴: `기타 수입(월)`, 예금 이자. 급여·부업 수입처럼 매달 들어오는 돈입니다.
- 한 번 들어옴: `일시 수입`. 상여금·퇴직금·만기 적금·중고 판매처럼 한 번만 들어오는 돈입니다.

- **기준일**(상단, 기본값 오늘)을 0개월로 놓고 m개월 시점의 값을 계산합니다.
- **적용 기간**: 월세·관리비·고정 지출·대출·월 수입은 시작일 ~ 종료일 사이의 달에만 효과가 납니다. 종료일을 비우면 계속 적용됩니다.
  계약직 급여처럼 끝나는 수입, 복직처럼 몇 달 뒤 시작하는 수입을 그대로 넣을 수 있습니다.
- **지출·수입 시점**: 보증금·일시 지출은 지출일, 일시 수입은 수입일을 지정할 수 있습니다.
  그 달이 되어야 순 자본에 반영되고, 비우면 기준일(0개월)에 오고 갑니다.
  목록에서는 `6개월 뒤 일시 -3,000,000원`, `6개월 뒤 일시 +3,000,000원` 처럼 몇 달 뒤인지 함께 보입니다.
- **대출**: 기간 동안 원금이 보유 자금에 들어가고(옵션) 잔액 기준 이자가 매달 나갑니다. 종료일에 잔액이 전액 상환됩니다.
- **상환 방식**: 대출 팝업에서 네 가지 중 고릅니다. 이자는 언제나 그 달 초 잔액 기준이라 원금이 줄면 이자도 줄어듭니다.

  | 방식 | 계산 | 만기(종료일) |
  |---|---|---|
  | 만기 일시 상환 | 기간 동안 이자만, 종료일에 원금 전액 | 없어도 됨 |
  | 원금 균등 | 매달 `원금 ÷ 기간` 씩 상환, 이자가 줄어 상환액도 매달 감소 | 필요 |
  | 원리금 균등 | 매달 같은 금액. `P·i·(1+i)^n / ((1+i)^n − 1)` | 필요 |
  | 매달 원금의 % | 원금의 x% 씩 매달 상환, 잔액이 0이 되면 끝 | 없어도 됨 |

  팝업에 월 상환액·총 이자·완납 시점이 바로 보입니다. 원금 균등과 원리금 균등은 종료일이 없으면 저장되지 않습니다.
  예전 파일에서 "매달 원금의 %" 만 있던 대출은 자동으로 그 방식으로 읽힙니다.
- **중도 상환**: 대출에 (날짜, 금액) 목록을 여러 건 넣을 수 있습니다. 정기 상환과 같이 쓸 수 있습니다. 상환한 달부터 잔액이 줄어 이자가 감소하고, 상환액만큼 순 자본이 줄어듭니다.
  원금을 보유 자금에 포함하지 않은 대출은 상환액과 만기 잔액이 그 달의 지출로 잡힙니다.
- **N개월 필요 자금** = (N개월 안에 나가는) 일시 지출 + 0..N-1개월 월 지출 합
- **N개월 수입** = (N개월 안에 들어오는) 일시 수입 + 0..N-1개월 월 수입 합
- **N개월 후 순 자본** = N개월 시점 보유 자금 − (그때까지 나간) 일시 지출 + (그때까지 들어온) 일시 수입 + 0..N-1개월 (월 수입 − 월 지출) 합
- **목표 달성률** = 순 자본 ÷ 목표 자본금, 부족액과 (월 순수입이 양수일 때) 추가로 필요한 개월 수를 함께 표시
- 오른쪽 아래 그래프는 0 ~ N개월 동안의 순 자본 추이
- **현금 부족 경고**: 순 자본이 마이너스로 떨어지는 달이 있으면 요약 아래에 빨간 카드가 뜹니다.
  처음 부족해지는 시점, 그때 순 자본, 최저점과 그 시점, 부족한 달 수를 보여줍니다.
  기간이 36개월보다 짧아도 최소 36개월까지 살펴봅니다. 그래프에도 부족 시작 지점에 빨간 세로선이 그려지고 0 아래가 붉게 칠해집니다.

## 조작

- `+ 항목 추가` → 팝업에서 이름 / 분류 / 금액(슬라이더+입력) / 적용 기간 / 연이율 / 중도 상환 입력
- 날짜는 `YYYY-MM-DD`. 숫자만 치면 하이픈이 자동으로 들어갑니다 (20260401 → 2026-04-01)
- 표의 행을 **더블클릭** → 수정 팝업
- `▲ ▼` 순서 변경, `X` 삭제(확인 팝업)
- **저장 위치**: 기본은 프로젝트 폴더의 `capital_data.json` 입니다. 창 맨 아래 "파일:" 에 현재 파일 경로가 항상 표시됩니다.
  - `저장`: 현재 파일에 저장. 완료되면 화면 아래에 경로가 적힌 알림이 뜹니다.
  - `다른 이름으로`: 파일 대화상자에서 원하는 폴더·이름으로 저장. 이후부터 그 파일이 현재 파일이 됩니다.
  - `불러오기`: 파일 대화상자에서 JSON 선택. 실패하면 빨간 알림이 뜹니다.
  - 앱을 켜면 `capital_data.json` 이 있을 때 자동으로 불러옵니다.
  - `엑셀`: 요약 · 항목 · 월별 추이(선 그래프 포함) · 비중(원형 그래프 포함) 4개 시트를 `.xlsx` 로 내보냅니다. `capital_calc/export_excel.py`
- **비중 카드**: 보유 자금 / 월 지출 / 월 수입 구성을 도넛 그래프와 퍼센트 범례로 보여줍니다. 조각이나 범례에 마우스를 올리면 강조됩니다.
- 슬라이더 상한: 목표 자본금·금액 모두 10억원. 더 큰 값은 입력칸에 직접 치면 범위가 자동으로 늘어납니다.
- **시나리오**: 상단 탭에서 시나리오를 여러 개 두고 비교합니다. 각 시나리오는 항목·기간·목표·기준일을 따로 가집니다.
  - `＋ 시나리오`: 빈 시나리오 추가 (기간·목표·기준일은 현재 것을 이어받음). `복제`: 현재 시나리오를 항목까지 복사.
  - 탭 클릭 = 전환, 더블클릭 또는 `이름` = 이름 변경. `시나리오 삭제` 는 2개 이상일 때만.
  - 추이 그래프에 다른 시나리오가 점선으로 겹쳐 그려지고, 아래 "시나리오 비교" 카드에 N개월 후 순 자본 · 현재 대비 차이 · 월 순수입 · 달성 예측이 나란히 나옵니다.
  - 저장 파일에는 모든 시나리오가 함께 들어갑니다 (`{"scenarios": [...], "active": n}`). 예전 형식(계획 하나) 파일도 그대로 읽힙니다.
  - 엑셀 내보내기 시 시나리오가 2개 이상이면 "시나리오 비교" 시트(선 그래프 포함)가 추가됩니다.

- 예전 저장 파일의 `기타 지출(일시)` 분류는 불러올 때 `일시 지출` 로 자동 변환됩니다.
