# 자본금 계산기 (Python + QML)

보증금 · 월세 · 관리비 · 대출 이자 · 은행 예금 등 항목을 리스트로 **추가/제거**하고,
기간(개월)과 **목표 자본금**을 기준으로 순 자본과 달성률을 계산하는 데스크톱 앱입니다.

백엔드(Python)와 프론트엔드(QML)를 분리한 구조입니다.

- `capital_calc/model.py` — 순수 계산 로직. Qt 를 전혀 모름.
- `capital_calc/backend.py` — 모델을 `QObject` / `QAbstractListModel` 로 감싸 QML 에 프로퍼티·시그널·슬롯으로 노출.
- `qml/` — 화면·레이아웃·애니메이션. Python 을 모르고 `backend` 객체만 바인딩.

QML 은 Qt Quick 씬그래프가 GPU(OpenGL/Direct3D)로 렌더링합니다.
항목 추가/삭제 슬라이드, 숫자 롤링, 진행 바 보간과 하이라이트, 그래프가 그려지는 애니메이션, 팝업 등장 효과가 들어 있습니다.
예전 OpenGL(GLFW + Dear ImGui) 버전은 `main_imgui.py` 로 남겨 두었습니다.

## 실행

```bash
pip install -r requirements.txt
python main.py
```

## 항목 분류와 계산 방식

| 묶음 | 분류 | 금액의 의미 | 보유 자금 | 일시 지출 | 월 지출 | 월 수입 | 일시 수입 |
|---|---|---|---|---|---|---|---|
| 자본 | 현금/자산 | 보유 금액 | ✔ | | | | |
| 자본 | 은행 예금 | 예금액 + 연이율 | ✔ | | | 원금×이율÷12 | |
| 자본 | 적금/저축(월) | 월 납입액 + 월 지원금 + 연이율 (납입 기간, 묶임) | ✔ (쌓인 만큼, 묶으면 만기에) | | 납입액만 | | |
| 자본 | 대출/이자 | 대출 원금 + 연이율 (적용 기간, 상환 방식, 중도 상환) | ✔ (옵션) | | 잔액×이율÷12 | | |
| 수입 | 월 수입 | 월 수입 (적용 기간) | | | | ✔ | |
| 수입 | 일시 수입 | 수입액 (수입일) | | | | | ✔ |
| 지출 | 월세 | 월세 (적용 기간) | | | ✔ | | |
| 지출 | 관리비 | 월 관리비 (적용 기간) | | | ✔ | | |
| 지출 | 고정 지출 | 매달 나가는 돈 (적용 기간) | | | ✔ | | |
| 지출 | 주거 | 전세·반전세·월세·매매 (보증금/매매가 + 월세, 입주일·만기) | | ✔ (만기 전까지) | 월세 | | |
| 지출 | 일시 지출 | 지출액 (지출일) | | ✔ | | | |

분류는 **자본 → 수입 → 지출** 순서이고, 각 묶음 안에서 매달 오고 가는 것이 먼저, 한 번만 오고 가는 것이 뒤에 옵니다. 목록의 `분류별 묶기` 와 팝업의 분류 선택도 같은 순서입니다.

지출과 수입 모두 **매달 오고 가는 것**과 **한 번만 오고 가는 것**으로 나뉩니다.

- 매달 나감: `월세`, `관리비`, `고정 지출`, 대출 이자. 보험료·통신비·식비·교통비처럼 이름이 따로 없는 월 지출은 `고정 지출` 에 넣습니다.
- 한 번 나감: `주거`(보증금·매매가), `일시 지출`. 이사비·중개수수료·취득세 같은 것입니다.
- **주거**: 집에 들어가는 돈은 `주거` 하나로 넣고 형태를 고릅니다.

  | 형태 | 금액 | 월세 | 만기에 |
  |---|---|---|---|
  | 전세 | 보증금 | 없음 | 돌려받음 |
  | 반전세 | 보증금 | 있음 | 돌려받음 |
  | 월세 | 보증금(소액) | 있음 | 돌려받음 |
  | 매매 | 매매가 | 없음 | 돌려받지 않음 (집으로 남음) |

  입주일에 보증금(매매가)이 나가고, 계약 만기를 넣으면 그 달부터 순 자본에 다시 들어옵니다. 만기를 비우면 계속 묶여 있는 것으로 봅니다.
  월세가 있는 형태는 입주일 ~ 만기 구간에만 월세가 나갑니다. 보증금 없이 월세만 내는 경우에는 `월세` 분류를 써도 됩니다.
  매매는 취득세·중개수수료·이사비를 `일시 지출` 로 따로 넣으세요.
- 매달 들어옴: `월 수입`, 예금 이자. 급여·부업 수입처럼 매달 들어오는 돈입니다.
- **적금/저축(월)**: 매달 나가지만 사라지지 않고 자본으로 쌓이는 돈입니다. 납입 기간 동안 매달 나가고 그만큼 보유 자금이 늘어서 순 자본은 그대로입니다.
  연이율을 넣으면 각 납입분이 묶여 있던 기간만큼 단리 이자가 붙고, 만기 뒤에는 납입도 이자도 멈춥니다.
  이미 모아 둔 목돈은 `은행 예금` 에 넣으세요.
- **월 지원금**: 청년도약계좌처럼 정부·회사가 보태 주는 돈입니다. 적금/저축에만 있습니다.
  - 내 돈 20만원 + 지원 30만원이면 **통장에는 매달 50만원이 쌓이고, 지갑에서는 20만원만 나갑니다.**
  - 그래서 지원금만큼 순 자본이 늘고, 이자도 50만원 전체에 붙습니다.
  - 목록 아래에 `내 돈 200,000원 + 지원 300,000원 = 매달 500,000원` 과 `받은 지원금 3,600,000원` 이 보입니다.
  - 엑셀 항목 시트에 `월 지원금` 열이 들어갑니다.
- **만기까지 묶임**: 적금은 자본이지만 만기 전까지는 손댈 수 없는 돈입니다. 팝업에서 `만기 전까지는 못 쓰는 돈` 을 켜면
  - 만기가 될 때까지 **보유 자금·순 자본·목표 달성률에서 빠집니다.** 나가는 납입액만 반영됩니다.
  - 만기에 원금 + 지원금 + 이자가 **한꺼번에 들어옵니다.** 요약의 `일시 수입` 과 `N개월 수입` 에 그 금액이 잡힙니다
    (보유 자금에는 안 들어갑니다 — 만기 전까지 못 쓰는 돈이니까요).
  - 목표 바에 청록색 `만기에 받을 적금` 구간으로 따로 보입니다 (보증금·대출과 같은 방식).
  - 만기(종료일)가 있어야 적용됩니다. 없으면 팝업과 목록이 그렇다고 알려 줍니다.
  - 이렇게 두면 적금에 가려져 있던 현금 부족이 제대로 드러납니다.
- 한 번 들어옴: `일시 수입`. 상여금·퇴직금·만기 적금·중고 판매처럼 한 번만 들어오는 돈입니다.

- **기준일**(상단, 기본값 오늘)을 0개월로 놓고 m개월 시점의 값을 계산합니다.
- **날짜(일)까지 셉니다.** 시간 축은 기준일에 못을 박은 한 달 간격의 눈금입니다.
  기준일이 10월 28일이면 0개월 = 10/28, 1개월 = 11/28, 2개월 = 12/28 입니다.
  항목 날짜는 **그 날이 지난 첫 눈금**으로 올려 붙입니다. 12월 1일에 나갈 돈이 11월 28일 칸에서
  미리 나가 버리면 안 되기 때문입니다 (2026-12-01 → 2개월). 종료일에서 기간을 거꾸로 구할 때도 같은 규칙입니다
  (기준일 2026-10-28 에 종료일 2029-01-15 → 27개월).
- **연 상승률**: 월 수입·월세·관리비·고정 지출에 해마다 오르는 비율을 넣을 수 있습니다 (급여 인상, 물가·월세 인상).
  시작한 지 1년이 지날 때마다 한 번씩 오릅니다. 그 사이에는 그대로입니다.
  팝업에 "3년 뒤 2,185,454원 (지금보다 +185,454원)" 처럼 미리 보여 주고, 목록 아래에는 "해마다 3% 인상" 이 붙습니다.
  엑셀 항목 시트에 `연 상승률(%)` 열이 들어갑니다.
- **적용 기간**: 월세·관리비·고정 지출·대출·월 수입은 시작일 ~ 종료일 사이의 달에만 효과가 납니다. 종료일을 비우면 계속 적용됩니다.
  계약직 급여처럼 끝나는 수입, 복직처럼 몇 달 뒤 시작하는 수입을 그대로 넣을 수 있습니다.
- **지출·수입 시점**: 보증금·일시 지출은 지출일, 일시 수입은 수입일을 지정할 수 있습니다.
  그 달이 되어야 순 자본에 반영되고, 비우면 기준일(0개월)에 오고 갑니다.
  목록에서는 `6개월 뒤 일시 -3,000,000원`, `6개월 뒤 일시 +3,000,000원` 처럼 몇 달 뒤인지 함께 보입니다.
- **되풀이 (자동차세·보험 연납)**: 일시 지출·일시 수입에 `되풀이` 가 있습니다. `한 번만 / 분기 / 반년 / 해마다` 중에 고르면
  **같은 날짜로 그 간격마다** 되풀이됩니다. 한 달 주기가 아닌 돈을 해마다 손으로 넣지 않아도 됩니다.
  - `되풀이 끝` 을 넣으면 그 달까지만 (비우면 계속). 목록에는 `해마다 · 36개월 안에 3번` 처럼 몇 번 들어오는지 나옵니다.
  - 기간 안에 들어오는 **횟수만큼** 일시 지출·수입 합계에 더해집니다. 가계부의 `계획 대비 실적` 도 회차마다 잡습니다.
  - **기준일보다 먼저 시작한 되풀이**도 괜찮습니다. 작년 6월부터 내던 자동차세라면 기준일 전 회차는 빼고 앞으로 낼 것만 셉니다.
  - 보증금처럼 **돌려받는 돈**과 이미 매달 오가는 분류에는 되풀이가 없습니다.
- **이자소득세 · 복리** (예금·적금): 이율을 넣으면 팝업에 두 칸이 나옵니다.
  - `이자소득세 15.4% 떼기` — **이자에서만** 뗍니다 (원금은 그대로). 새로 넣는 예금·적금은 **켜진 채로 시작**합니다.
    청년도약계좌·ISA 같은 **비과세 상품이면 끄세요**. 이미 넣어 둔 항목은 그대로 둡니다 (숫자가 저절로 바뀌지 않게).
  - `복리로 굴리기` — 예금은 이자를 빼지 않고 잔액에 쌓습니다 (그래서 `월 수입` 에 안 잡히고 `보유 자금` 이 늡니다).
    적금은 납입분마다 월복리로 붙습니다. 끄면 단리입니다 — **은행 적금은 보통 단리**입니다.
  - 목록 아래에 `단리 · 세전`, `복리 · 세후 (이자 15.4%)` 처럼 무엇으로 계산했는지 늘 적어 둡니다.
  - 대출 이자에는 세금이 없습니다 (내는 돈이라서). 칸도 나오지 않습니다.
- **물가 (지금 돈으로 얼마?)**: 요약 아래 `물가 [3] %` 에 연 상승률을 넣으면 `지금 돈으로 45,652,271원` 이 함께 나옵니다.
  - **계산을 바꾸지 않습니다.** 기간 끝의 금액을 지금 가치로 환산해 보여 줄 뿐입니다.
  - 목표를 정해 뒀으면 `목표 3,000만원은 24개월 뒤 지금 돈 2,827만원 만큼입니다` 도 함께 나옵니다.
- **대출**: 기간 동안 원금이 보유 자금에 들어가고(옵션) 잔액 기준 이자가 매달 나갑니다. 종료일에 잔액이 전액 상환됩니다.
  목록 아래에 `월 이자 133,167원` 이 항상 보입니다. 아직 시작 전인 대출도 얼마씩 나갈지 미리 알 수 있습니다.
- **상환 방식**: 대출 팝업에서 네 가지 중 고릅니다. 이자는 언제나 그 달 초 잔액 기준이라 원금이 줄면 이자도 줄어듭니다.

  | 방식 | 계산 | 만기(종료일) |
  |---|---|---|
  | 만기 일시 상환 | 기간 동안 이자만, 종료일에 원금 전액 | 없어도 됨 |
  | 원금 균등 | 매달 `원금 ÷ 기간` 씩 상환, 이자가 줄어 상환액도 매달 감소 | 필요 |
  | 원리금 균등 | 매달 같은 금액. `P·i·(1+i)^n / ((1+i)^n − 1)` | 필요 |
  | 매달 원금의 % | 원금의 x% 씩 매달 상환, 잔액이 0이 되면 끝 | 없어도 됨 |

  팝업에 월 상환액·총 이자·완납 시점이 바로 보입니다. 원금 균등과 원리금 균등은 종료일이 없으면 저장되지 않습니다.
  예전 파일에서 "매달 원금의 %" 만 있던 대출은 자동으로 그 방식으로 읽힙니다.
- **중도 상환**: 대출에 (날짜, 금액) 목록을 여러 건 넣을 수 있습니다. 정기 상환과 같이 쓸 수 있습니다. 상환한 달부터 잔액이 줄어 이자가 감소하고, 상환액만큼 순 자본이 줄어듭니다.
  원금을 보유 자금에 포함하지 않은 대출은 상환액과 만기 잔액이 그 달의 지출로 잡힙니다.
- **보유 자금 (지금)** = 0개월 시점의 현금·예금·적금 잔액 (+ 옵션에 따라 대출 원금)
- **N개월 후 보유 자금** = 같은 것을 N개월 시점에서. 적금이 쌓이고 예금 이자가 붙어 지금과 다릅니다.
  적금 납입액은 `월 지출` 로 빠져나가지만 그만큼 통장에 쌓이므로, 빠지는 쪽만 보이면 숫자가 맞지 않아 보입니다.
  그래서 두 줄을 같이 두고 차액을 아래에 적어 둡니다. 순 자본은 **N개월 후 보유 자금** 에서 출발합니다.
- **N개월 필요 자금** = (N개월 안에 나가는) 일시 지출 + 0..N-1개월 월 지출 합
- **N개월 수입** = (N개월 안에 들어오는) 일시 수입 + 0..N-1개월 월 수입 합
- **월 지출 · 월 수입 · 월 순수입**: 요약의 이 세 줄은 **기간 전체의 평균**입니다.
  기간 중에 시작하는 대출 이자나 월세도 들어갑니다 (4개월 뒤에 이자가 나가기 시작하면 그만큼 평균이 올라갑니다).
  기간 중에 값이 달라지면 이름에 `(평균)` 이 붙고, 아래에 `지금 +1,464,250원 → 13개월째 +1,191,167원` 처럼 시작과 끝을 같이 보여 줍니다.
  기간을 0으로 두면 이번 달 하나만 봅니다.
- **N개월 후 순 자본** = N개월 시점 보유 자금 − (그때까지 나간) 일시 지출 + (그때까지 들어온) 일시 수입 + 0..N-1개월 (월 수입 − 월 지출) 합
- **목표 달성률** = 순 자본 ÷ 목표 자본금, 부족액과 (월 순수입이 양수일 때) 추가로 필요한 개월 수를 함께 표시
- **앞으로 들어올 돈**: 기간이 끝난 뒤에 들어올 돈은 진행 바에 색을 달리해 이어 붙습니다.
  - 파란색 = 돌려받을 보증금 (반환일이 기간 뒤)
  - 청록색 = 만기에 받을 적금 (묶어 둔 적금의 만기가 기간 뒤)
  - 보라색 = 받을 대출 (원금을 자본에 넣는 대출이 기간 뒤에 실행)
  - 지금 순 자본만으로는 0% 라도 "0.0% → 85.0%" 처럼 다 들어온 뒤의 비율을 같이 보여 줍니다.
  - 바 아래에 종류별 금액·시점과 "다 들어와도 N원 모자랍니다" 가 나옵니다. 실제로 더 마련해야 하는 금액입니다.
  - 기간 안에 들어오는 것은 이미 순 자본에 있으므로 따로 세지 않습니다.
    원금을 자본에 넣지 않은 대출도 세지 않습니다 (빌려서 바로 나가는 돈이라서).
- 오른쪽 아래 그래프는 0 ~ N개월 동안의 순 자본 추이
- **현금 부족 경고**: 순 자본이 마이너스로 떨어지는 달이 있으면 요약 아래에 빨간 카드가 뜹니다.
  처음 부족해지는 시점, 그때 순 자본, 최저점과 그 시점, 부족한 달 수를 보여줍니다.
  기간이 36개월보다 짧아도 최소 36개월까지 살펴봅니다. 그래프에도 부족 시작 지점에 빨간 세로선이 그려지고 0 아래가 붉게 칠해집니다.

## 일부러 넣지 않은 것

계산을 단순하게 두려고 뺀 것들입니다. 숫자를 읽을 때 염두에 두세요.

- **물가 상승은 연 상승률을 직접 넣은 항목에만** 적용됩니다. 요약의 `물가 %` 는 계산을 바꾸지 않고 '지금 돈' 으로 환산만 합니다.
- **대출 이자는 월 단위**로 잔액 × (연이율 ÷ 12) 입니다. 실제 은행의 일할 계산과 며칠치만큼 다를 수 있습니다.
- **시간 축이 한 달 간격**입니다. 날짜(일)는 어느 달 칸에 넣을지를 정할 뿐, 하루 단위로 쪼개지 않습니다.

## 저장

- **저장은 통째로 바꿔치기**입니다. 같은 폴더의 `.tmp` 에 전부 쓰고 디스크까지 내려보낸 뒤 한 번에 바꿉니다.
  쓰는 도중에 앱이 죽거나 디스크가 차도 **원본이 잘린 채 남지 않습니다**.
- **직전 저장본이 `capital_data.json.bak`** 으로 남습니다. 잘못 저장했으면 `.bak` 의 `.bak` 을 떼고 불러오면 됩니다.
- **자동 저장**: 무언가 고치고 **4초**가 지나면 저절로 저장합니다. 계속 고치는 동안에는 기다렸다가, 손을 뗀 뒤에 한 번 저장합니다.
  - 아직 한 번도 저장한 적이 없으면(파일이 없으면) 자동 저장은 돌지 않습니다. 멋대로 파일을 만들어 두지 않으려는 것입니다 — `저장` 을 한 번 누르면 그때부터 켜집니다.
  - 저장이 실패하면 자동 저장을 멈추고 빨간 알림을 띄웁니다. 같은 실패를 계속 두드리지 않습니다.
- **지금 저장되었는지** 머리줄에서 바로 보입니다: `● 저장 안 됨` (노랑) 또는 `자동 저장 14:03`. `저장` 단추에도 `●` 가 붙습니다.
- **저장 안 된 채로 창을 닫으려 하면 묻습니다**: `저장하고 닫기` / `저장 않고 닫기` / `취소`.
- `Ctrl+S` 로 언제든 저장합니다.

## 조작

- **되돌리기 (`Ctrl+Z`)**: 상단의 `되돌리기` 단추, 또는 `Ctrl+Z`. 되돌린 것은 `다시` (`Ctrl+Shift+Z`, `Ctrl+Y`) 로 다시 실행합니다.
  - **계획과 가계부를 가리지 않습니다.** 항목 추가·수정·삭제·순서, 시나리오 추가·복제·삭제·이름,
    가계부 내역·분류·예산·고정 항목, 지난달 복사, 계획에서 가져오기, 예시 데이터 불러오기, 파일 불러오기까지 한 더미에 쌓입니다.
  - **최근 30번**까지 기억합니다. 더미는 메모리에만 있어서 앱을 끄면 사라집니다.
  - 아무것도 바뀌지 않은 동작(이름이 겹쳐 거절된 가져오기 등)은 더미에 쌓지 않습니다. 눌렀는데 아무 일도 안 일어나는 일이 없도록.
  - 기간·목표 슬라이더처럼 값 하나만 다시 치면 되는 것은 더미에 넣지 않습니다 (슬라이더를 끌 때마다 쌓이면 더미가 금세 가득 찹니다).
  - 단추에 마우스를 올리면 **무엇이 취소되는지** 보여 줍니다 (`방금 한 일: 항목 삭제`).
  - 되돌려도 **보고 있던 달과 화면은 그대로** 둡니다.
- `+ 항목 추가` → 팝업에서 이름 / 분류 / 금액(슬라이더+입력) / 적용 기간 / 연이율 / 중도 상환 입력
- 날짜는 `YYYY-MM-DD`. 숫자만 치면 하이픈이 자동으로 들어갑니다 (20260401 → 2026-04-01).
  다 치고 0.2초가 지나면 **엔터를 치지 않아도** 반영됩니다 (날짜가 온전할 때만).
- **기간은 날짜로 정합니다.** 상단의 `기준일` 과 `종료일`, 두 날짜가 기간입니다. 개월 수를 직접 치는 칸은 없습니다.
  옆에 `기간  13개월` 이 계산 결과로 따라 붙고, 그 아래 `− 6개월 1년 2년 3년 5년 ＋` 단추로 종료일을 빠르게 옮깁니다
  (`−` `＋` 는 종료일을 한 달씩 — 꾹 눌러도 연속으로 움직이지 않습니다. 숫자 단추는 기준일 + 그만큼으로,
  지금 기간과 맞는 단추에 불이 들어옵니다).
  직접 친 종료일은 **친 그대로** 남습니다. 기준일 + N개월로 바꿔 쓰지 않으니 `2029-01-15` 는 `2029-01-15` 로 보입니다
  (단추로 옮기면 그때 기준일 + N개월 날짜로 바뀝니다).
- **항목 잠시 끄기**: 행의 `⏸` 를 누르면 그 항목이 **계산에서만 빠집니다**. 목록에는 이름에 줄이 그어진 채 흐리게 남고, `▶` 로 다시 켭니다.
  - "이 대출을 안 받으면 어떻게 되지" 를 지웠다 다시 넣지 않고 봅니다. 꺼 둔 항목을 고쳐도 꺼진 채로 있습니다.
  - 요약·그래프·목표·분류별 합계·비중, 엑셀의 비중 시트까지 모두 꺼진 항목을 뺀 숫자입니다
    (엑셀 `항목` 시트에는 `(꺼짐)` 이 붙어 그대로 남습니다).
  - 카드 제목에 `(9개, 1개 꺼짐)` 으로 몇 개가 빠져 있는지 나옵니다. 저장 파일에도 함께 들어갑니다.
- 표의 행을 **더블클릭** → 수정 팝업
- `▲ ▼` 순서 변경, `X` 삭제(확인 팝업).
  **분류별 묶기를 켠 상태에서는 같은 분류 안에서만** 올라가고 내려갑니다 (보이는 차례와 원본 차례가 다르기 때문).
  그 분류의 맨 위·맨 아래 항목은 해당 단추가 꺼집니다.
- **저장 위치**: 기본은 프로젝트 폴더의 `capital_data.json` 입니다. 창 맨 아래 "파일:" 에 현재 파일 경로가 항상 표시됩니다.
  - `저장`: 현재 파일에 저장. 완료되면 화면 아래에 경로가 적힌 알림이 뜹니다.
  - `다른 이름으로`: 파일 대화상자에서 원하는 폴더·이름으로 저장. 이후부터 그 파일이 현재 파일이 됩니다.
  - `불러오기`: 파일 대화상자에서 JSON 선택. 실패하면 빨간 알림이 뜹니다.
  - 앱을 켜면 `capital_data.json` 이 있을 때 자동으로 불러옵니다.
  - `엑셀`: 요약 · 항목 · 월별 추이(선 그래프 포함) · 비중(원형 그래프 포함) 4개 시트를 `.xlsx` 로 내보냅니다. `capital_calc/export_excel.py`
- **비중 카드**: 도넛 그래프와 퍼센트 범례로 구성을 보여줍니다. 조각이나 범례에 마우스를 올리면 강조됩니다.
  - **목표 구성**(기본): 목표를 무엇으로 채우는지 — 순 자본 / 보증금 반환 / 적금 만기 / 받을 대출 / 아직 모자람.
    **목표 바와 같은 색**이라 바와 도넛이 한 눈에 이어집니다. 모자랄 때는 조각 합이 목표와 같고, 넘칠 때는 가운데에 "다 모으면" 합계가 나옵니다.
  - 보유 자금 / 월 지출 / 월 수입: 항목별 구성.
- 슬라이더 상한: 목표 자본금·금액 모두 10억원. 더 큰 값은 입력칸에 직접 치면 범위가 자동으로 늘어납니다.
- 모든 슬라이더에 **− / ＋ 버튼**이 있습니다. 한 번에 한 눈금씩 움직이고, 누르고 있으면 계속 움직입니다.
  입력칸 위에서 마우스 휠을 굴려도 같은 눈금으로 조정됩니다.
- **슬라이더와 입력칸은 0.2초 뒤에 반영됩니다** (`SliderInput.dragDelay`, 기본 200ms).
  - 끄는 동안에는 숫자·말풍선만 손을 따라가고, **손을 떼면 기다리지 않고 바로** 반영됩니다.
    끄는 도중 0.2초 멈추면 그때도 한 번 반영합니다.
  - 숫자를 칠 때도 같습니다. 멈추고 0.2초면 반영되고, 엔터를 치면 즉시입니다.
  - 기다리는 동안에는 값 라벨이 살짝 흐려집니다.
  - 기간·목표 자본금·항목 금액·월세·연 상승률·예산 — 모든 슬라이더가 같은 간격을 씁니다.
  - 40단계짜리 드래그 한 번 기준: 다시 계산 **78회 → 2회**.
- **시나리오**: 상단 탭에서 시나리오를 여러 개 두고 비교합니다. 각 시나리오는 항목·기간·목표·기준일을 따로 가집니다.
  - `＋ 시나리오`: 빈 시나리오 추가 (기간·목표·기준일은 현재 것을 이어받음). `복제`: 현재 시나리오를 항목까지 복사.
  - 탭 클릭 = 전환, 더블클릭 또는 `이름` = 이름 변경. `시나리오 삭제` 는 2개 이상일 때만.
  - 추이 그래프에 다른 시나리오가 점선으로 겹쳐 그려지고, 아래 "시나리오 비교" 카드에 N개월 후 순 자본 · 현재 대비 차이 · 월 순수입 · 달성 예측이 나란히 나옵니다.
  - 저장 파일에는 모든 시나리오가 함께 들어갑니다 (`{"scenarios": [...], "active": n}`). 예전 형식(계획 하나) 파일도 그대로 읽힙니다.
  - 엑셀 내보내기 시 시나리오가 2개 이상이면 "시나리오 비교" 시트(선 그래프 포함)가 추가됩니다.

- 예전 저장 파일의 분류 이름은 불러올 때 자동 변환됩니다: `기타 지출(일시)` → `일시 지출`, `보증금` → `주거`, `기타 수입(월)` → `월 수입`, `고정 지출(월)` → `고정 지출`.

## 가계부

계획이 "앞으로 이렇게 될 것 같다" 라면 가계부는 "실제로 이만큼 쓰고 벌었다" 입니다.
상단 제목 옆의 **계획 / 가계부** 로 화면을 바꿉니다.

- `＋ 내역 추가` → 날짜 / 분류 / 금액 / 쓴 곳 / 메모. 분류가 수입인지 지출인지 자동으로 정해지고 팝업에 표시됩니다.
  - 수입 분류: 급여, 부업, 상여금, 이자/배당, 용돈, 기타 수입
  - 지출 분류: 식비, 주거/관리비, 교통, 통신, 보험, 의료, 생활용품, 문화/여가, 경조사, 교육, 저축/투자, 대출 상환, 기타 지출
  - **분류 직접 만들기**: 분류 칸 옆 `＋` 를 누르고 이름(12자까지)을 적은 뒤 `지출` / `수입` 을 고르면 됩니다.
    만든 분류는 바로 골라지고, 저장 파일에 함께 들어가 다음에도 남아 있습니다. 지출로 만든 분류는 예산도 정할 수 있습니다.
    직접 만든 분류를 고르면 옆에 `✕` 가 나와 지울 수 있습니다 — 단, 그 분류로 적어 둔 내역이 있으면 거절합니다 (몇 건인지 알려 줍니다).
    기본 분류는 지울 수 없습니다.
- **기간 고르기**: 왼쪽 위에서 연도를 고르고 `전체`(그 해 전부) 또는 1~12월을 누릅니다. 기록이 없는 달은 흐리게 보입니다.
- **월별 표**: 그 해 12개월의 수입·지출·남은 돈이 한눈에 보이고, 줄을 누르면 그 달로 넘어갑니다.
- **분류별**: 선택한 기간의 지출(또는 수입) 구성을 도넛 그래프로 보여줍니다.
- **연도별**: 2년 이상 기록이 쌓이면 해마다 수입·지출·남은 돈이 아래에 나옵니다.
- 내역 행을 **더블클릭** 하면 수정, `⟳` 로 고정 항목 등록, `✕` 로 삭제합니다. 삭제는 되돌릴 수 없어서 `11월 5일 '월세·관리비' -600,000원 내역을 삭제할까요?` 처럼
  무엇을 지우는지 보여 주고 한 번 묻습니다. 날짜마다 구분줄이 들어가고 그 날 수지가 오른쪽에 붙습니다.
- **파일에서 가져오기**: `파일에서` 단추로 은행·카드사 **CSV**, **엑셀(.xlsx)**, **메모장(.txt)** 내역을 읽어 옵니다. 팝업에 글을 **그대로 붙여넣어도** 됩니다.
  - 머리글(`거래일`·`이용일`·`날짜` / `금액`·`출금`·`입금` / `적요`·`가맹점명`·`내용` / `분류` / `결제수단` / `메모`)을 찾아 짝지어 읽습니다.
    위에 붙은 제목·계좌번호 줄은 건너뛰고, 입금·출금이 따로 있으면 그것으로 수입/지출을 가립니다.
  - 머리글이 없으면 **줄마다 날짜와 금액을 찾습니다**: `11/13 점심 12,000 카드` 같은 메모도 들어옵니다
    (`+` 가 붙은 금액은 수입, 아는 분류·결제수단 이름이 섞여 있으면 알아서 넣습니다).
  - 인코딩(`utf-8` / `cp949`)과 구분자(쉼표·탭·세미콜론)는 알아서 가립니다. 날짜는 `2026-11-02` `2026.11.02` `20261102` `11/02` `2026년 11월 2일` 모두 읽습니다.
  - **미리보기**로 몇 건인지·무엇이 들어가는지 보고 넣습니다. 날짜·분류·내용·결제수단·금액이 줄마다 보입니다.
  - **이미 있는 내역**(날짜·금액·내용·수입지출이 같은 것)은 `이미 있음` 으로 표시하고 기본으로 건너뜁니다. 같은 파일을 두 번 읽어도 중복되지 않습니다.
  - 결제수단이 비어 있는 줄에 **한꺼번에 넣을 결제수단**을 정할 수 있습니다.
  - 없는 분류는 새로 만들어 넣고, 이름이 길거나 겹쳐 못 만들면 `기타` 로 넣고 메모에 원래 이름을 남깁니다.
  - 못 읽은 줄은 **몇 번째 줄이 왜** 안 됐는지 알려 주고 건너뜁니다. 가져온 것은 `Ctrl+Z` 로 **한 번에** 되돌아갑니다.
- **결제수단**: 내역마다 카드·현금·계좌이체·간편결제·자동이체를 적어 둡니다. 목록에 없는 이름(`신한카드` 처럼)도 **직접 적으면** 됩니다 —
  그 이름을 쓰는 내역이 있는 동안 목록에 남습니다. 비워 두면 `지정 안 함` 으로 모입니다.
  - 내역 줄의 이름 아래에 작게 나오고, 검색어로도 걸립니다.
  - 거르기 줄의 `결제수단` 으로 그것만 봅니다 (그 기간에 실제로 쓴 것만 목록에 나옵니다).
  - 오른쪽 도넛에서 `분류` / `결제수단` 을 눌러 **무엇으로 나눠 볼지** 고릅니다.
  - 고정 지출·수입에도 결제수단을 정해 두면 저절로 적히는 내역에 그대로 붙습니다. 반복·지난달 복사도 물려받습니다.
  - 엑셀 `가계부 내역` 시트에 `결제수단` 열이 들어갑니다.
- **여러 건 한꺼번에**: 줄 왼쪽의 네모칸을 눌러 고릅니다. 하나라도 고르면 목록 위에 띠가 나옵니다.
  - 띠에는 `몇 건 · 합계` 가 나오고, `모두` (보이는 것 모두 고르기 / 다 골랐으면 풀기) · `결제수단 바꾸기` · `분류 바꾸기` · `삭제` · `해제` 가 있습니다.
  - **분류 바꾸기**는 고른 줄의 분류를 한꺼번에 바꿉니다. 수입/지출도 새 분류를 따라갑니다
    (지출로 적힌 것을 `용돈` 으로 바꾸면 수입이 됩니다). 바꾼 뒤에도 고른 채로 두어 이어서 또 바꿀 수 있습니다.
  - **삭제**는 몇 건인지와 합계를 보여 주고 한 번 묻습니다. 되돌리기(`Ctrl+Z`)로 **한 번에** 되살아납니다.
  - `보이는 것 모두` 는 지금 걸러져 보이는 줄만 고릅니다. 달이나 필터를 옮겨도 고른 것은 그대로 남습니다
    (보이지 않는 줄이 골라져 있을 수 있으니, 띠의 건수를 보고 `해제` 하세요).
  - 줄이 지워져 번호가 밀리는 일(한 건 삭제·비우기·되돌리기) 뒤에는 고른 것이 저절로 풀립니다.
- **검색·거르기**: 내용·분류·메모를 검색하고, 수입/지출과 분류로 거릅니다. 거르는 중에는 제목이 `3 / 12건` 처럼 바뀌고
  오른쪽에 걸러진 합계가 나옵니다. `거르기 해제` 로 한 번에 풉니다. 달을 옮기면 그 달에 없는 분류 필터는 저절로 풀립니다.
- **정렬 · 금액으로 찾기**: 목록 위의 `정렬` 에서 `날짜` / `금액` 을 고릅니다. **같은 것을 다시 누르면 반대 방향**입니다 (↓ 큰 것·최신 먼저, ↑ 작은 것·오래된 것 먼저).
  - 금액순으로 보면 날짜 구분줄은 접힙니다 (날짜가 뒤섞여 뜻을 잃기 때문입니다).
  - 옆의 `금액  최소 ~ 최대` 로 그 범위만 봅니다. 한쪽만 넣으면 `얼마 이상` / `얼마 이하` 가 됩니다.
    **부호는 보지 않습니다** — 지출 3만원과 수입 3만원은 같은 3만원입니다.
  - 금액 범위도 거르기라서 제목이 `3 / 12건` 으로 바뀌고 `거르기 해제` 로 함께 풀립니다 (정렬은 그대로 둡니다).
- **반복 입력**: 추가 팝업에서 `한 번 / 2달 / 3달 / 6달 / 12달` 을 고르면 같은 내역이 다음 달부터 한꺼번에 들어갑니다.
  31일처럼 그 달에 없는 날짜는 말일로 맞춥니다 (1/31 → 2/28).
- **저장하고 계속**: 팝업을 닫지 않고 저장해서 여러 건을 이어서 적습니다 (날짜·분류는 그대로).
- **고정 지출·수입**: `고정` 버튼에서 월세·통신비·급여처럼 달마다 똑같이 오가는 돈을 적어 둡니다.
  - 이름 / 분류 / 금액 / 매달 며칟날 / 기간(`2026-11` ~ 비우면 계속) / 메모를 정합니다.
  - **앱을 열 때 밀린 달까지 한꺼번에 적힙니다.** 몇 달 만에 켜도 그동안의 달이 한 번씩 채워집니다.
  - 적힌 내역에는 `고정` 표시가 붙습니다. 그 줄을 고치거나 지우는 것은 보통 내역과 같습니다 —
    **지운 달은 다시 적지 않습니다** (지웠다는 건 그 달은 아니었다는 뜻이므로).
  - `⏸` 로 잠시 쉬게 하고 `▶` 로 다시 돌립니다. 다시 돌리면 쉬는 동안 밀린 달도 그때 적습니다.
  - `수정` 으로 금액을 바꿔도 **이미 적어 둔 지난 내역은 그대로** 두고 다음 달부터 새 금액으로 적습니다.
  - `✕` 로 지울 때 이미 적어 둔 내역을 함께 지울지 고를 수 있습니다. 그냥 지우면 실제로 쓴 돈이므로 내역은 남습니다.
  - 내역 행의 `⟳` 를 누르면 그 내역을 고정 항목으로 올립니다 (그 달은 이미 적혀 있으므로 **다음 달부터**).
  - 31일처럼 그 달에 없는 날짜는 말일로 맞춥니다 (1/31 → 2/28).
- **지난달 복사**: 월을 고른 상태에서 지난달 내역을 통째로 가져옵니다. 날짜·분류·금액이 같은 내역은 건너뛰므로 두 번 눌러도 중복되지 않습니다.
- **계획에서 가져오기**: 계획 항목을 가계부 내역으로 옮깁니다.
  - 계획 화면의 각 항목 오른쪽 `▤` 버튼 → 그 항목 하나만
  - 가계부 화면의 `계획에서 가져오기` 버튼 → 기록할 수 있는 항목을 한꺼번에
  - **이름이 같은 내역이 그 달에 이미 있으면 넣지 않고 빨간 알림을 띄웁니다.** 여러 번 눌러도 중복되지 않습니다.
  - 분류는 이렇게 짝지어집니다: 월세·관리비·주거 → `주거/관리비`, 고정 지출·일시 지출 → `기타 지출`,
    월 수입 → `급여`, 일시 수입 → `기타 수입`, 대출/이자 → `대출 상환`, 적금/저축 → `저축/투자`.
    현금/자산과 은행 예금은 오고 가는 돈이 아니라 기록할 수 없습니다.
  - 금액은 그 달에 실제로 오고 가는 돈입니다 (대출은 그 달 상환액, 월 항목은 월 금액).
  - 날짜는 고른 달의 오늘 날짜, 달을 안 골랐으면 오늘입니다. 메모에 `계획에서 가져옴` 이 남습니다.
- **지난달 대비**: 집계 카드에 지난달(연 단위면 작년) 대비 지출·수입 증감이 금액과 퍼센트로 나옵니다.
- **분류별 예산**: `예산` 버튼에서 분류마다 한 달 한도를 정합니다.
  - 오른쪽 `분류별 예산` 카드에 합계와 분류별 막대가 나옵니다. 85%를 넘으면 노랑, 예산을 넘으면 빨강입니다.
  - 예산을 안 정한 분류도 쓴 돈이 있으면 `(예산 없음)` 으로 함께 보입니다.
  - 연 단위로 보면 한도를 12배로 놓고 비교하고, 카드 제목에 `12개월분` 이 붙습니다.
  - 팝업의 `실적으로 채우기` 는 그 기간에 실제로 쓴 금액(월평균, 천원 단위)을 예산으로 넣습니다.
  - 예산은 가계부와 같은 파일에 저장되고, 엑셀에 `가계부 예산` 시트(분류 / 한 달 예산 / 월평균 실제 / 차이)가 추가됩니다.
- **계획 대비 실적**: 지금 보고 있는 시나리오의 그 달 계획과 가계부 실적을 나란히 비교합니다.
  - 계획 수입 = 월 수입 + 그 달의 일시 수입 + 보증금 반환
  - 계획 지출 = 월 지출 + 그 달에 걸린 일시 지출 + 대출 원금 상환 (원금을 자본에 넣은 대출은 월 지출에 안 잡히므로 따로 더합니다)
  - 수입·남은 돈은 계획보다 많으면 초록, 지출은 적으면 초록입니다. 연 단위로 보면 기준일 이후의 달을 모두 더합니다.
  - 카드 위의 `총액` / `분류별` 로 바꿔 봅니다.
  - **분류별**: 계획 항목을 각자의 `가계부 분류` 로 묶어 분류마다 계획·실제·차이를 보여 줍니다.
    계획에 없던 분류(식비처럼)는 `계획 없음` 으로 흐리게 함께 나옵니다 — 그게 바로 계획에 없던 지출입니다.
    지출은 적을수록, 수입은 많을수록 초록입니다. 많이 걸린 7개까지 보여 줍니다.
  - **가계부 분류 정하기**: 계획의 분류(11가지)와 가계부의 분류는 체계가 다릅니다. 항목 팝업의 `가계부 분류` 에서
    그 짝을 직접 고를 수 있습니다 (`자동` 이면 아래 짝짓기표대로). `생활비 (식비·통신)` 를 `식비` 로 묶는 식입니다.
    이 값은 `계획에서 가져오기` 에도 그대로 쓰입니다.
  - 엑셀 `가계부 월별` 시트에도 계획 수입 · 계획 지출 · 지출 차이 열이 들어갑니다.
- 앱을 켜거나 파일을 불러오면 **가장 최근에 기록한 달**이 열립니다.
- 가계부는 시나리오와 무관하게 하나만 있고, 계획과 **같은 파일에 함께 저장**됩니다
  (`{"ledger": {"entries": [...], "budgets": {...}, "custom": {...}, "fixed": [...]}}`, 버전 3). 가계부가 없는 예전 파일도 그대로 열립니다.
- 엑셀 내보내기에 기록이 있으면 **가계부 내역 / 가계부 월별(막대 그래프) / 가계부 연도별** 시트가 추가됩니다.

## 한눈에 보기

상단의 **한눈에** 로 넘어가면 계획(자본금)과 가계부를 한 화면에 모아 봅니다.
여기서는 아무것도 따로 계산하지 않습니다 — 계획 화면·가계부 화면이 쓰는 값을 그대로 가져옵니다.

- **네 칸 요약**: 지금 보유 자금 / 기간 끝의 순 자본 / 목표까지 / 이번 달 가계부 수지.
- 순 자본이 마이너스가 되는 달이 있으면 그 위에 빨간 줄로 알려 줍니다.
- **순 자본 추이**: 계획 화면과 같은 그래프 (시나리오를 모두 겹쳐 그리고 목표선·달성 지점 표시).
  기간이 12개월보다 짧아도 최소 12개월까지 그립니다.
- **최근 12개월 수입·지출**: 이번 달까지 열두 달의 막대. 초록이 수입, 빨강이 지출이고
  이번 달 칸은 배경이 밝습니다. 막대에 마우스를 올리면 그 달의 수입·지출·수지가 뜹니다.
  옆에 기록이 있는 달의 월평균 수지, 가장 좋았던 달과 힘들었던 달이 함께 나옵니다.
- **최근 12개월 구성**: 분류별 비중 도넛. `지출` / `수입` 을 눌러 바꿉니다.
- **이번 달 계획 대비 실적**: 계획 지출·수입과 실제 지출·수입을 나란히 놓고 차이를 말로 알려 줍니다.
- **이번 달 예산 · 고정 지출·수입**: 많이 쓴 분류 네 개의 막대(85% 노랑, 초과 빨강)와 고정 항목의 한 달 수지.
- **시나리오 비교**: 시나리오가 둘 이상이면 기간 끝의 순 자본을 지금 시나리오와의 차이와 함께 보여 줍니다.

## 그리기

화면은 Qt Quick 장면 그래프가 그립니다. 윈도우에서는 **Direct3D 11** 을 쓰므로 창·목록·글자는 모두 GPU 가 그립니다.

두 그래프(`TrendChart`, `PieChart`)는 예전에 `Canvas` 로 그렸습니다. `Canvas` 는 매번 CPU 에서 그림을 그려
텍스처로 올리는 방식이라, 마우스를 움직이거나 값이 바뀔 때마다 CPU 가 그래프 영역을 통째로 다시 칠했습니다.
지금은 **`QtQuick.Shapes`** 로 바꿔서 선·호·면이 장면 그래프의 도형이 되었고, 눈금·마커·라벨은 평범한
`Rectangle` 과 `Text` 입니다. 전부 GPU 가 그립니다.

1200×700 그래프를 쉬지 않고 다시 그리게 하고 잰 CPU 시간입니다 (각 3회).

| | CPU / 프레임 | CPU 점유 |
|---|---|---|
| `Canvas` (예전) | 2.6 ~ 3.0 ms | 15 ~ 18% |
| `QtQuick.Shapes` (지금) | 1.2 ~ 1.7 ms | 7 ~ 10% |

그림은 그대로입니다. 같은 데이터로 창 전체를 찍어 비교하면 다른 픽셀이 0.16% (가장자리 안티앨리어싱) 뿐입니다.

도넛의 마우스 판정은 `PieChart.sliceAt(dx, dy)` 로 떼어 두었습니다. 가운데에서 떨어진 거리와 각도로
몇 번째 조각인지 돌려주고, 링 밖이면 -1 입니다.

### 다시 계산을 줄인 것

기간을 1개월 바꾸면 QML 의 모든 바인딩이 다시 평가되면서 같은 계산이 수없이 되풀이됐습니다.
실제 데이터(항목 20개, 시나리오 2개) 기준으로 `Plan.summary()` 가 **187번**, 현금 부족 계산이 8번,
`net_at()` 이 1130번 불렸고 한 번 바꾸는 데 **262ms** 가 들었습니다.

- `Backend._cache`: 요약·현금 부족·들어올 돈·추이를 한 번만 계산하고 담아 둡니다.
  `summaryChanged` 가 올 때마다 버리므로 묵은 값이 나갈 일은 없습니다.
- `Plan.net_series(n)`: 0..n 개월 순 자본을 한 번에 구합니다.
  `net_at(m)` 은 0..m-1 개월 월 수지를 매번 다시 더하므로 여러 달을 연달아 물으면 비용이 제곱으로 늡니다.
  그래프와 현금 부족 계산이 이걸 씁니다.

- `Plan.first_month_reaching(금액, after, limit)`: 목표에 닿는 첫 달을 찾습니다.
  예전에는 `net_at(0), net_at(1), …` 을 차례로 불렀는데, `net_at(m)` 이 매번 0개월부터 다시 더하는 탓에
  600개월까지 뒤지면 비용이 폭발했습니다. 지금은 달을 한 번만 훑으면서 닿는 순간 멈춥니다.
- `Summary.net` 도 한 번만 구해 둡니다 (여러 바인딩이 읽습니다).

그 결과 한 번 바꾸는 비용이 **262ms → 38ms** 가 되었습니다.

| | 전 | 후 |
|---|---:|---:|
| 기간 1개월 변경 | 262 ms | **38 ms** |
| `Plan.summary()` | 187회 | 5회 |
| 현금 부족 계산 | 8회 | 1회 |
| `net_at()` | 1130회 | 12회 |

담아 두는 값은 **메모리에만** 있습니다. 파일에는 입력한 것(항목·기간·목표·가계부)만 저장하고,
계산 결과는 저장하지 않습니다. 저장해 두면 다음에 열 때 입력과 어긋날 수 있고, 어차피 한 번 계산하면
그만이기 때문입니다.
