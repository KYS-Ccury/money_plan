# 자본금 계산기 (Python + QML)

보증금 · 월세 · 관리비 · 대출 이자 · 은행 예금 등 항목을 리스트로 **추가/제거**하고,
기간(개월)과 **목표 자본금**을 기준으로 순 자본과 달성률을 계산하는 데스크톱 앱입니다.

백엔드(Python)와 프론트엔드(QML)를 분리한 구조입니다.

- `capital_calc/model.py` — 순수 계산 로직. Qt 를 전혀 모름.
- `capital_calc/backend.py` — 모델을 `QObject` / `QAbstractListModel` 로 감싸 QML 에 프로퍼티·시그널·슬롯으로 노출.
- `qml/` — 화면·레이아웃·애니메이션. Python 을 모르고 `backend` 객체만 바인딩.

QML 은 Qt Quick 씬그래프가 GPU(OpenGL/Direct3D)로 렌더링합니다.
항목 추가/삭제 슬라이드, 숫자 롤링, 진행 바 보간과 하이라이트, 그래프가 그려지는 애니메이션, 팝업 등장 효과가 들어 있습니다.
예전 OpenGL(GLFW + Dear ImGui) 버전은 `main_imgui.py` 로 남겨 두었습니다.

## 실행

```bash
pip install -r requirements.txt
python main.py
```

## 항목 분류와 계산 방식

| 묶음 | 분류 | 금액의 의미 | 보유 자금 | 일시 지출 | 월 지출 | 월 수입 | 일시 수입 |
|---|---|---|---|---|---|---|---|
| 자본 | 현금/자산 | 보유 금액 | ✔ | | | | |
| 자본 | 은행 예금 | 예금액 + 연이율 | ✔ | | | 원금×이율÷12 | |
| 자본 | 적금/저축(월) | 월 납입액 + 월 지원금 + 연이율 (납입 기간, 묶임) | ✔ (쌓인 만큼, 묶으면 만기에) | | 납입액만 | | |
| 자본 | 대출/이자 | 대출 원금 + 연이율 (적용 기간, 상환 방식, 중도 상환) | ✔ (옵션) | | 잔액×이율÷12 | | |
| 수입 | 월 수입 | 월 수입 (적용 기간) | | | | ✔ | |
| 수입 | 일시 수입 | 수입액 (수입일) | | | | | ✔ |
| 지출 | 월세 | 월세 (적용 기간) | | | ✔ | | |
| 지출 | 관리비 | 월 관리비 (적용 기간) | | | ✔ | | |
| 지출 | 고정 지출 | 매달 나가는 돈 (적용 기간) | | | ✔ | | |
| 지출 | 주거 | 전세·반전세·월세·매매 (보증금/매매가 + 월세, 입주일·만기) | | ✔ (만기 전까지) | 월세 | | |
| 지출 | 일시 지출 | 지출액 (지출일) | | ✔ | | | |

분류는 **자본 → 수입 → 지출** 순서이고, 각 묶음 안에서 매달 오고 가는 것이 먼저, 한 번만 오고 가는 것이 뒤에 옵니다. 목록의 `분류별 묶기` 와 팝업의 분류 선택도 같은 순서입니다.

지출과 수입 모두 **매달 오고 가는 것**과 **한 번만 오고 가는 것**으로 나뉩니다.

- 매달 나감: `월세`, `관리비`, `고정 지출`, 대출 이자. 보험료·통신비·식비·교통비처럼 이름이 따로 없는 월 지출은 `고정 지출` 에 넣습니다.
- 한 번 나감: `주거`(보증금·매매가), `일시 지출`. 이사비·중개수수료·취득세 같은 것입니다.
- **주거**: 집에 들어가는 돈은 `주거` 하나로 넣고 형태를 고릅니다.

  | 형태 | 금액 | 월세 | 만기에 |
  |---|---|---|---|
  | 전세 | 보증금 | 없음 | 돌려받음 |
  | 반전세 | 보증금 | 있음 | 돌려받음 |
  | 월세 | 보증금(소액) | 있음 | 돌려받음 |
  | 매매 | 매매가 | 없음 | 돌려받지 않음 (집으로 남음) |

  입주일에 보증금(매매가)이 나가고, 계약 만기를 넣으면 그 달부터 순 자본에 다시 들어옵니다. 만기를 비우면 계속 묶여 있는 것으로 봅니다.
  월세가 있는 형태는 입주일 ~ 만기 구간에만 월세가 나갑니다. 보증금 없이 월세만 내는 경우에는 `월세` 분류를 써도 됩니다.
  매매는 취득세·중개수수료·이사비를 `일시 지출` 로 따로 넣으세요.
- 매달 들어옴: `월 수입`, 예금 이자. 급여·부업 수입처럼 매달 들어오는 돈입니다.
- **적금/저축(월)**: 매달 나가지만 사라지지 않고 자본으로 쌓이는 돈입니다. 납입 기간 동안 매달 나가고 그만큼 보유 자금이 늘어서 순 자본은 그대로입니다.
  연이율을 넣으면 각 납입분이 묶여 있던 기간만큼 단리 이자가 붙고, 만기 뒤에는 납입도 이자도 멈춥니다.
  이미 모아 둔 목돈은 `은행 예금` 에 넣으세요.
- **월 지원금**: 청년도약계좌처럼 정부·회사가 보태 주는 돈입니다. 적금/저축에만 있습니다.
  - 내 돈 20만원 + 지원 30만원이면 **통장에는 매달 50만원이 쌓이고, 지갑에서는 20만원만 나갑니다.**
  - 그래서 지원금만큼 순 자본이 늘고, 이자도 50만원 전체에 붙습니다.
  - 목록 아래에 `내 돈 200,000원 + 지원 300,000원 = 매달 500,000원` 과 `받은 지원금 3,600,000원` 이 보입니다.
  - 엑셀 항목 시트에 `월 지원금` 열이 들어갑니다.
- **만기까지 묶임**: 적금은 자본이지만 만기 전까지는 손댈 수 없는 돈입니다. 팝업에서 `만기 전까지는 못 쓰는 돈` 을 켜면
  - 만기가 될 때까지 **보유 자금·순 자본·목표 달성률에서 빠집니다.** 나가는 납입액만 반영됩니다.
  - 만기에 원금 + 지원금 + 이자가 **한꺼번에 들어옵니다.** 요약의 `일시 수입` 과 `N개월 수입` 에 그 금액이 잡힙니다
    (보유 자금에는 안 들어갑니다 — 만기 전까지 못 쓰는 돈이니까요).
  - 목표 바에 청록색 `만기에 받을 적금` 구간으로 따로 보입니다 (보증금·대출과 같은 방식).
  - 만기(종료일)가 있어야 적용됩니다. 없으면 팝업과 목록이 그렇다고 알려 줍니다.
  - 이렇게 두면 적금에 가려져 있던 현금 부족이 제대로 드러납니다.
- 한 번 들어옴: `일시 수입`. 상여금·퇴직금·만기 적금·중고 판매처럼 한 번만 들어오는 돈입니다.

- **기준일**(상단, 기본값 오늘)을 0개월로 놓고 m개월 시점의 값을 계산합니다.
- **연 상승률**: 월 수입·월세·관리비·고정 지출에 해마다 오르는 비율을 넣을 수 있습니다 (급여 인상, 물가·월세 인상).
  시작한 지 1년이 지날 때마다 한 번씩 오릅니다. 그 사이에는 그대로입니다.
  팝업에 "3년 뒤 2,185,454원 (지금보다 +185,454원)" 처럼 미리 보여 주고, 목록 아래에는 "해마다 3% 인상" 이 붙습니다.
  엑셀 항목 시트에 `연 상승률(%)` 열이 들어갑니다.
- **적용 기간**: 월세·관리비·고정 지출·대출·월 수입은 시작일 ~ 종료일 사이의 달에만 효과가 납니다. 종료일을 비우면 계속 적용됩니다.
  계약직 급여처럼 끝나는 수입, 복직처럼 몇 달 뒤 시작하는 수입을 그대로 넣을 수 있습니다.
- **지출·수입 시점**: 보증금·일시 지출은 지출일, 일시 수입은 수입일을 지정할 수 있습니다.
  그 달이 되어야 순 자본에 반영되고, 비우면 기준일(0개월)에 오고 갑니다.
  목록에서는 `6개월 뒤 일시 -3,000,000원`, `6개월 뒤 일시 +3,000,000원` 처럼 몇 달 뒤인지 함께 보입니다.
- **대출**: 기간 동안 원금이 보유 자금에 들어가고(옵션) 잔액 기준 이자가 매달 나갑니다. 종료일에 잔액이 전액 상환됩니다.
  목록 아래에 `월 이자 133,167원` 이 항상 보입니다. 아직 시작 전인 대출도 얼마씩 나갈지 미리 알 수 있습니다.
- **상환 방식**: 대출 팝업에서 네 가지 중 고릅니다. 이자는 언제나 그 달 초 잔액 기준이라 원금이 줄면 이자도 줄어듭니다.

  | 방식 | 계산 | 만기(종료일) |
  |---|---|---|
  | 만기 일시 상환 | 기간 동안 이자만, 종료일에 원금 전액 | 없어도 됨 |
  | 원금 균등 | 매달 `원금 ÷ 기간` 씩 상환, 이자가 줄어 상환액도 매달 감소 | 필요 |
  | 원리금 균등 | 매달 같은 금액. `P·i·(1+i)^n / ((1+i)^n − 1)` | 필요 |
  | 매달 원금의 % | 원금의 x% 씩 매달 상환, 잔액이 0이 되면 끝 | 없어도 됨 |

  팝업에 월 상환액·총 이자·완납 시점이 바로 보입니다. 원금 균등과 원리금 균등은 종료일이 없으면 저장되지 않습니다.
  예전 파일에서 "매달 원금의 %" 만 있던 대출은 자동으로 그 방식으로 읽힙니다.
- **중도 상환**: 대출에 (날짜, 금액) 목록을 여러 건 넣을 수 있습니다. 정기 상환과 같이 쓸 수 있습니다. 상환한 달부터 잔액이 줄어 이자가 감소하고, 상환액만큼 순 자본이 줄어듭니다.
  원금을 보유 자금에 포함하지 않은 대출은 상환액과 만기 잔액이 그 달의 지출로 잡힙니다.
- **N개월 필요 자금** = (N개월 안에 나가는) 일시 지출 + 0..N-1개월 월 지출 합
- **N개월 수입** = (N개월 안에 들어오는) 일시 수입 + 0..N-1개월 월 수입 합
- **월 지출 · 월 수입 · 월 순수입**: 요약의 이 세 줄은 **기간 전체의 평균**입니다.
  기간 중에 시작하는 대출 이자나 월세도 들어갑니다 (4개월 뒤에 이자가 나가기 시작하면 그만큼 평균이 올라갑니다).
  기간 중에 값이 달라지면 이름에 `(평균)` 이 붙고, 아래에 `지금 +1,464,250원 → 13개월째 +1,191,167원` 처럼 시작과 끝을 같이 보여 줍니다.
  기간을 0으로 두면 이번 달 하나만 봅니다.
- **N개월 후 순 자본** = N개월 시점 보유 자금 − (그때까지 나간) 일시 지출 + (그때까지 들어온) 일시 수입 + 0..N-1개월 (월 수입 − 월 지출) 합
- **목표 달성률** = 순 자본 ÷ 목표 자본금, 부족액과 (월 순수입이 양수일 때) 추가로 필요한 개월 수를 함께 표시
- **앞으로 들어올 돈**: 기간이 끝난 뒤에 들어올 돈은 진행 바에 색을 달리해 이어 붙습니다.
  - 파란색 = 돌려받을 보증금 (반환일이 기간 뒤)
  - 청록색 = 만기에 받을 적금 (묶어 둔 적금의 만기가 기간 뒤)
  - 보라색 = 받을 대출 (원금을 자본에 넣는 대출이 기간 뒤에 실행)
  - 지금 순 자본만으로는 0% 라도 "0.0% → 85.0%" 처럼 다 들어온 뒤의 비율을 같이 보여 줍니다.
  - 바 아래에 종류별 금액·시점과 "다 들어와도 N원 모자랍니다" 가 나옵니다. 실제로 더 마련해야 하는 금액입니다.
  - 기간 안에 들어오는 것은 이미 순 자본에 있으므로 따로 세지 않습니다.
    원금을 자본에 넣지 않은 대출도 세지 않습니다 (빌려서 바로 나가는 돈이라서).
- 오른쪽 아래 그래프는 0 ~ N개월 동안의 순 자본 추이
- **현금 부족 경고**: 순 자본이 마이너스로 떨어지는 달이 있으면 요약 아래에 빨간 카드가 뜹니다.
  처음 부족해지는 시점, 그때 순 자본, 최저점과 그 시점, 부족한 달 수를 보여줍니다.
  기간이 36개월보다 짧아도 최소 36개월까지 살펴봅니다. 그래프에도 부족 시작 지점에 빨간 세로선이 그려지고 0 아래가 붉게 칠해집니다.

## 조작

- `+ 항목 추가` → 팝업에서 이름 / 분류 / 금액(슬라이더+입력) / 적용 기간 / 연이율 / 중도 상환 입력
- 날짜는 `YYYY-MM-DD`. 숫자만 치면 하이픈이 자동으로 들어갑니다 (20260401 → 2026-04-01)
- 표의 행을 **더블클릭** → 수정 팝업
- `▲ ▼` 순서 변경, `X` 삭제(확인 팝업)
- **저장 위치**: 기본은 프로젝트 폴더의 `capital_data.json` 입니다. 창 맨 아래 "파일:" 에 현재 파일 경로가 항상 표시됩니다.
  - `저장`: 현재 파일에 저장. 완료되면 화면 아래에 경로가 적힌 알림이 뜹니다.
  - `다른 이름으로`: 파일 대화상자에서 원하는 폴더·이름으로 저장. 이후부터 그 파일이 현재 파일이 됩니다.
  - `불러오기`: 파일 대화상자에서 JSON 선택. 실패하면 빨간 알림이 뜹니다.
  - 앱을 켜면 `capital_data.json` 이 있을 때 자동으로 불러옵니다.
  - `엑셀`: 요약 · 항목 · 월별 추이(선 그래프 포함) · 비중(원형 그래프 포함) 4개 시트를 `.xlsx` 로 내보냅니다. `capital_calc/export_excel.py`
- **비중 카드**: 도넛 그래프와 퍼센트 범례로 구성을 보여줍니다. 조각이나 범례에 마우스를 올리면 강조됩니다.
  - **목표 구성**(기본): 목표를 무엇으로 채우는지 — 순 자본 / 보증금 반환 / 적금 만기 / 받을 대출 / 아직 모자람.
    **목표 바와 같은 색**이라 바와 도넛이 한 눈에 이어집니다. 모자랄 때는 조각 합이 목표와 같고, 넘칠 때는 가운데에 "다 모으면" 합계가 나옵니다.
  - 보유 자금 / 월 지출 / 월 수입: 항목별 구성.
- 슬라이더 상한: 목표 자본금·금액 모두 10억원. 더 큰 값은 입력칸에 직접 치면 범위가 자동으로 늘어납니다.
- 모든 슬라이더에 **− / ＋ 버튼**이 있습니다. 한 번에 한 눈금씩 움직이고, 누르고 있으면 계속 움직입니다.
  입력칸 위에서 마우스 휠을 굴려도 같은 눈금으로 조정됩니다.
- 입력칸에 숫자를 치면 **엔터를 치지 않아도** 잠깐 멈춘 뒤(0.35초) 바로 반영됩니다. 엔터를 치면 즉시 반영됩니다.
- **시나리오**: 상단 탭에서 시나리오를 여러 개 두고 비교합니다. 각 시나리오는 항목·기간·목표·기준일을 따로 가집니다.
  - `＋ 시나리오`: 빈 시나리오 추가 (기간·목표·기준일은 현재 것을 이어받음). `복제`: 현재 시나리오를 항목까지 복사.
  - 탭 클릭 = 전환, 더블클릭 또는 `이름` = 이름 변경. `시나리오 삭제` 는 2개 이상일 때만.
  - 추이 그래프에 다른 시나리오가 점선으로 겹쳐 그려지고, 아래 "시나리오 비교" 카드에 N개월 후 순 자본 · 현재 대비 차이 · 월 순수입 · 달성 예측이 나란히 나옵니다.
  - 저장 파일에는 모든 시나리오가 함께 들어갑니다 (`{"scenarios": [...], "active": n}`). 예전 형식(계획 하나) 파일도 그대로 읽힙니다.
  - 엑셀 내보내기 시 시나리오가 2개 이상이면 "시나리오 비교" 시트(선 그래프 포함)가 추가됩니다.

- 예전 저장 파일의 분류 이름은 불러올 때 자동 변환됩니다: `기타 지출(일시)` → `일시 지출`, `보증금` → `주거`, `기타 수입(월)` → `월 수입`, `고정 지출(월)` → `고정 지출`.

## 가계부

계획이 "앞으로 이렇게 될 것 같다" 라면 가계부는 "실제로 이만큼 쓰고 벌었다" 입니다.
상단 제목 옆의 **계획 / 가계부** 로 화면을 바꿉니다.

- `＋ 내역 추가` → 날짜 / 분류 / 금액 / 쓴 곳 / 메모. 분류가 수입인지 지출인지 자동으로 정해지고 팝업에 표시됩니다.
  - 수입 분류: 급여, 부업, 상여금, 이자/배당, 용돈, 기타 수입
  - 지출 분류: 식비, 주거/관리비, 교통, 통신, 보험, 의료, 생활용품, 문화/여가, 경조사, 교육, 저축/투자, 대출 상환, 기타 지출
- **기간 고르기**: 왼쪽 위에서 연도를 고르고 `전체`(그 해 전부) 또는 1~12월을 누릅니다. 기록이 없는 달은 흐리게 보입니다.
- **월별 표**: 그 해 12개월의 수입·지출·남은 돈이 한눈에 보이고, 줄을 누르면 그 달로 넘어갑니다.
- **분류별**: 선택한 기간의 지출(또는 수입) 구성을 도넛 그래프로 보여줍니다.
- **연도별**: 2년 이상 기록이 쌓이면 해마다 수입·지출·남은 돈이 아래에 나옵니다.
- 내역 행을 **더블클릭** 하면 수정, `✕` 로 삭제합니다. 날짜마다 구분줄이 들어가고 그 날 수지가 오른쪽에 붙습니다.
- **검색·거르기**: 내용·분류·메모를 검색하고, 수입/지출과 분류로 거릅니다. 거르는 중에는 제목이 `3 / 12건` 처럼 바뀌고
  오른쪽에 걸러진 합계가 나옵니다. `거르기 해제` 로 한 번에 풉니다. 달을 옮기면 그 달에 없는 분류 필터는 저절로 풀립니다.
- **반복 입력**: 추가 팝업에서 `한 번 / 2달 / 3달 / 6달 / 12달` 을 고르면 같은 내역이 다음 달부터 한꺼번에 들어갑니다.
  31일처럼 그 달에 없는 날짜는 말일로 맞춥니다 (1/31 → 2/28).
- **저장하고 계속**: 팝업을 닫지 않고 저장해서 여러 건을 이어서 적습니다 (날짜·분류는 그대로).
- **지난달 복사**: 월을 고른 상태에서 지난달 내역을 통째로 가져옵니다. 날짜·분류·금액이 같은 내역은 건너뛰므로 두 번 눌러도 중복되지 않습니다.
- **계획에서 가져오기**: 계획 항목을 가계부 내역으로 옮깁니다.
  - 계획 화면의 각 항목 오른쪽 `▤` 버튼 → 그 항목 하나만
  - 가계부 화면의 `계획에서 가져오기` 버튼 → 기록할 수 있는 항목을 한꺼번에
  - **이름이 같은 내역이 그 달에 이미 있으면 넣지 않고 빨간 알림을 띄웁니다.** 여러 번 눌러도 중복되지 않습니다.
  - 분류는 이렇게 짝지어집니다: 월세·관리비·주거 → `주거/관리비`, 고정 지출·일시 지출 → `기타 지출`,
    월 수입 → `급여`, 일시 수입 → `기타 수입`, 대출/이자 → `대출 상환`, 적금/저축 → `저축/투자`.
    현금/자산과 은행 예금은 오고 가는 돈이 아니라 기록할 수 없습니다.
  - 금액은 그 달에 실제로 오고 가는 돈입니다 (대출은 그 달 상환액, 월 항목은 월 금액).
  - 날짜는 고른 달의 오늘 날짜, 달을 안 골랐으면 오늘입니다. 메모에 `계획에서 가져옴` 이 남습니다.
- **지난달 대비**: 집계 카드에 지난달(연 단위면 작년) 대비 지출·수입 증감이 금액과 퍼센트로 나옵니다.
- **분류별 예산**: `예산` 버튼에서 분류마다 한 달 한도를 정합니다.
  - 오른쪽 `분류별 예산` 카드에 합계와 분류별 막대가 나옵니다. 85%를 넘으면 노랑, 예산을 넘으면 빨강입니다.
  - 예산을 안 정한 분류도 쓴 돈이 있으면 `(예산 없음)` 으로 함께 보입니다.
  - 연 단위로 보면 한도를 12배로 놓고 비교하고, 카드 제목에 `12개월분` 이 붙습니다.
  - 팝업의 `실적으로 채우기` 는 그 기간에 실제로 쓴 금액(월평균, 천원 단위)을 예산으로 넣습니다.
  - 예산은 가계부와 같은 파일에 저장되고, 엑셀에 `가계부 예산` 시트(분류 / 한 달 예산 / 월평균 실제 / 차이)가 추가됩니다.
- **계획 대비 실적**: 지금 보고 있는 시나리오의 그 달 계획과 가계부 실적을 나란히 비교합니다.
  - 계획 수입 = 월 수입 + 그 달의 일시 수입 + 보증금 반환
  - 계획 지출 = 월 지출 + 그 달에 걸린 일시 지출 + 대출 원금 상환 (원금을 자본에 넣은 대출은 월 지출에 안 잡히므로 따로 더합니다)
  - 수입·남은 돈은 계획보다 많으면 초록, 지출은 적으면 초록입니다. 연 단위로 보면 기준일 이후의 달을 모두 더합니다.
  - 계획의 분류와 가계부의 분류는 체계가 달라서 **총액만** 비교합니다.
  - 엑셀 `가계부 월별` 시트에도 계획 수입 · 계획 지출 · 지출 차이 열이 들어갑니다.
- 앱을 켜거나 파일을 불러오면 **가장 최근에 기록한 달**이 열립니다.
- 가계부는 시나리오와 무관하게 하나만 있고, 계획과 **같은 파일에 함께 저장**됩니다
  (`{"ledger": {"entries": [...]}}`, 버전 3). 가계부가 없는 예전 파일도 그대로 열립니다.
- 엑셀 내보내기에 기록이 있으면 **가계부 내역 / 가계부 월별(막대 그래프) / 가계부 연도별** 시트가 추가됩니다.
